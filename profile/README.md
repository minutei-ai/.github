# Minutei

**Seu escritório, nativo em IA.**

Construímos o [Minutei](https://minutei.legal), um espaço de trabalho jurídico com a Capi: pesquisa, leitura de processos e elaboração de minutas com as fontes à vista. O profissional revisa e decide.

Aqui publicamos ferramentas de busca, execução de agentes, extração de dados e avaliação de harnesses jurídicos.

## Projetos abertos

| Projeto | O que faz |
| --- | --- |
| [Benchmarks](https://github.com/minutei-ai/benchmarks) | Suítes para avaliar ferramentas, tarefas jurídicas, memória entre sessões e casos longos. Casos sintéticos, com contratos e avaliadores próprios. |
| [Nimbo](https://github.com/minutei-ai/nimbo) | Motor de navegador em Rust para extrair dados de páginas com JavaScript. Executa nativamente e em WebAssembly; versão 0.1. |
| [Kannin](https://github.com/minutei-ai/kannin) | Busca BM25, vetorial e híbrida em Cloudflare Workers, com documentos e índices no R2. |
| [Boxes](https://github.com/minutei-ai/boxes) | Sandboxes experimentais para agentes em Rust/Wasm, dentro de Cloudflare Workers, com arquivos persistidos no R2. |

Cada repositório documenta instalação, limites, validação e licença. Para contribuir ou relatar um problema, use as instruções e as issues do projeto correspondente.
